用 Claude Code 自定义 hook 拦截危险命令

为了防止 Claude Code 执行危险命令（如删除文件或修改系统配置），可以创建自定义 hook 来拦截并提示确认。

  • 在项目根目录创建 .claude/hooks/ 文件夹。
  • 创建文件 pre_command.sh，内容如下：
#!/bin/bash
# 拦截包含 rm -rf 或 sudo 的命令
if echo "$CLAUDE_COMMAND" | grep -qE "rm -rf|sudo"; then
  echo "⚠️ 危险命令被拦截: $CLAUDE_COMMAND"
  echo "是否允许执行？(y/N)"
  read -r response
  if [ "$response" != "y" ]; then
    exit 1
  fi
fi
  • 赋予执行权限：chmod +x .claude/hooks/pre_command.sh
  • 在 Claude Code 配置中启用 hook：在 claude.json 中添加 "hooks": [".claude/hooks/pre_command.sh"]。

这样每次执行危险操作前都会收到确认提示，有效防止误操作。
