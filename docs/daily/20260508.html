用 HuggingFace 加载 Gemma 4 并启用推测解码

Google 开源的 Gemma 4 模型支持推测解码，可大幅提升推理速度。以下示例使用 transformers 库加载模型并启用推测解码（需安装 transformers>=4.48 及 accelerate）。

from transformers import AutoModelForCausalLM, AutoTokenizer, GenerationConfig

model_name = "google/gemma-4-9b-it"
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForCausalLM.from_pretrained(
    model_name,
    device_map="auto",
    torch_dtype="auto"
)
# 配置推测解码参数
config = GenerationConfig(
    max_new_tokens=512,
    do_sample=False,
    speculation_length=3,       # 推测步数
    num_beams=1,
    use_cache=True
)
prompt = "解释量子计算的基本原理"
inputs = tokenizer(prompt, return_tensors="pt").to(model.device)
outputs = model.generate(**inputs, generation_config=config)
print(tokenizer.decode(outputs[0], skip_special_tokens=True))

调整 speculation_length 可平衡速度与精度，建议从 2~5 开始尝试。`
