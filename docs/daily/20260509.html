用Claude Code自定义hook拦截危险命令

Claude Code支持自定义hook，可在执行命令前进行安全检查。以下是一个拦截危险命令的示例hook配置：

  • 在项目根目录创建 .claude/hooks/pre-command 文件，内容如下：
#!/bin/bash
# 拦截危险命令
if [[ "$1" == "rm -rf /" ]] || [[ "$1" == "shutdown" ]]; then
  echo "危险命令被拦截: $1"
  exit 1
fi
  • 赋予执行权限：chmod +x .claude/hooks/pre-command
  • 在Claude Code中启用hook：在.claude/settings.json中添加：
{
  "hooks": {
    "pre-command": ".claude/hooks/pre-command"
  }
}

现在，当Claude尝试执行危险命令时，hook会阻止并提示。你可以根据需要扩展规则列表。
